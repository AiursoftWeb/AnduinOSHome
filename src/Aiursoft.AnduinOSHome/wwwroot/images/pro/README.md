# Pro preview screenshots

These are unedited captures of AnduinOS, not rendered product mockups.

- `encryption-preview.png`: Driver Center in a development build, captured during
  the 7 November 2026 encrypted-installation GUI verification. It displays status
  and credential-management entry points, without any password or recovery key.
- `recovery-preview.png`: the independent Recovery Environment, captured on
  9 November 2026 by booting a real installed system in QEMU/KVM, running
  `anduinos-recovery-env` version `2.1.0-13+resolute`. The blue controls are
  the actual interface. A keyboard-only virtual machine avoids capturing a
  pointer. The snapshot entry is from the test installation.

The page labels development and installation-layout limitations next to the images.
These captures do not establish general availability or full Pro release acceptance.
The hero reuses the site's existing `sc.webp` desktop screenshot.

All product visuals use these actual captures. CSS adds frames and lighting
around them; screenshot contents are not recolored or fabricated. No stock
photography or generated device imagery is included.
